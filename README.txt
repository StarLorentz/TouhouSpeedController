东方变速器 v0.1.0
==================

一、软件定位
------------
东方变速器是由 StarLorentz 制作的非官方免费工具，用于东方Project Windows
单机作品的弹幕练习。游戏以 60 帧为原速：30 帧为 0.5 倍速，45 帧为
0.75 倍速，15 帧为 0.25 倍速，13 帧约为 0.217 倍速。

本工具不包含恶意功能，不修改游戏文件或存档，也不提供联网游戏作弊功能。
其工作方式是向用户选定的东方游戏进程加载开源计时组件，因此部分安全软件
可能产生误报。

二、适用范围和测试状态
----------------------
程序默认识别 TH06 至 TH20 正作，也能显示常见的 thXXX 小数作进程，并自动
判断游戏是 32 位还是 64 位。

已实测：TH11 东方地灵殿、TH18 东方虹龙洞
理论支持：TH06–TH10、TH12–TH17、TH19–TH20（等待逐作测试）

“理论支持”表示程序已经包含对应进程识别规则，并不代表所有发行版本、汉化
补丁或兼容性设置都已经实机确认。

三、使用方法
------------
1. 启动东方游戏，进入标题画面。
2. 双击“东方变速器.exe”。
3. 等待“应用帧率”按钮启用，选择游戏进程。
4. 输入目标帧率，然后点击“应用帧率”。
5. 点击“恢复 60 帧”即可回到正常速度。
6. 正常关闭变速器时，程序也会恢复为 60 帧。

少数以管理员身份启动的游戏，需要右键本程序并选择“以管理员身份运行”。
TH06 等老游戏若自身兼容性或垂直同步异常，应先让游戏稳定以 60 帧运行。
