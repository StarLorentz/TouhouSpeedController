东方变速器 v0.1.1
==================

一、软件定位
------------
东方变速器是由 StarLorentz 制作的非官方免费工具，用于东方Project Windows
单机作品的弹幕练习。游戏以 60 帧为原速：30 帧为 0.5 倍速，45 帧为
0.75 倍速，15 帧为 0.25 倍速，13 帧约为 0.217 倍速。

本工具不包含恶意功能，不修改游戏文件或存档，也不提供联网游戏作弊功能。
其工作方式是向用户选定的东方游戏进程加载开源计时组件，因此部分安全软件
可能产生误报。

二、适用范围和测试状态
----------------------
程序默认识别 TH06 至 TH20 正作，也能显示常见的 thXXX 小数作进程，并自动
判断游戏是 32 位还是 64 位。v0.1.1 明确适配 Steam《东方红魔乡：
原典》的 th06c.exe 和《东方红魔乡：新典》的 th06nc.exe，同时完善常见
汉化版主程序名称的识别。

已实测变速：Steam TH06 原典、新典，以及 TH07、TH10、TH11、TH14、TH15、
TH17、TH18、TH20
识别规则支持：TH06–TH20 正作及常见 thXXX 小数作

“已实测变速”表示已在本机对应版本完成启动、进程识别、注入、速度切换和
恢复。不同发行版本、汉化补丁或兼容性设置仍可能存在差异。

三、使用方法
------------
1. 启动东方游戏，进入标题画面。
2. 双击“东方变速器.exe”。
3. 等待“应用帧率”按钮启用，选择游戏进程。
4. 输入目标帧率，然后点击“应用帧率”。
5. 点击“恢复 60 帧”即可回到正常速度。
6. 正常关闭变速器时，程序也会恢复为 60 帧。

少数以管理员身份启动的游戏，需要右键本程序并选择“以管理员身份运行”。
TH06 等老游戏若自身兼容性或垂直同步异常，应先让游戏稳定以 60 帧运行。

开发分支附加说明
--------------
开发版窗口获得焦点时会临时置顶；切换到游戏或其他程序后会取消置顶。
按 Ctrl+Shift+C 可从其他窗口呼出变速器；变速器在前台时再按一次会最小化。
若这个组合已被其他程序占用，
窗口标题会显示“快捷键被占用”，其他功能仍可使用。独占全屏游戏可能
限制普通窗口显示，建议使用窗口化或无边框窗口模式。
若游戏前台拦截普通快捷键，开发版会在东方游戏窗口位于前台时
额外检查 Ctrl+Shift+C 的按键状态并尝试呼出窗口，不依赖下拉框当前选择。
呼出后仍请确认下拉框选中要操作的游戏；这一路径不会监测其他程序中的按键组合。
状态框会显示本次由“系统快捷键”还是“游戏窗口按键检测”识别。

本开发版新增 TH16 已验证 th16.exe 的资源读取、单项修改、残机/Bomb 无限，
以及“无敌（实验）”。使用者确认该 EXE 在日文和汉化使用方式下均可修改资源；
独立的 th16c.exe 仍未适配。
TH14、TH15、TH17、TH18、TH20 本机日文版可读取并分别修改残机、Bomb、
Bomb 碎片及 Power。碎片专指 Bomb 碎片，不提供残机碎片设置。
TH14、TH15、TH17、TH18、TH20 的残机、Bomb、Bomb 碎片已由使用者
在关卡内验证。Power 数字会改变，但攻击要等游戏内部事件重新计算档位
后才同步，例如拾取 P 跨过整数档位，或死亡后重建。TH20 标题画面的
资源读数未通过校验，须在关卡内读取。
这些仍是开发版功能，不应作为正式适配发布；TH14、TH15、TH17、TH18
的无限资源暂未开放。
本机精确 EXE 版本的无敌实验候选现覆盖 TH07、TH10、TH11、TH14、TH15、
TH16、TH17、TH18、TH20。TH07、TH10、TH11 目前仅接入无敌，资源修改未接入；
选中游戏后可直接勾选“无敌”，无需先点“读取当前值”。TH14、TH15 请在
关卡中先点“读取当前值”，再勾选无敌。TH07 修订版及 TH10、TH11、
TH14、TH15 日文 EXE 的无敌已获使用者关卡确认。
此外，本机精确版本的 th10chs.exe、th10cht.exe、th11c.exe 已通过
受击函数和调用点静态比对，加入无敌候选；汉化 EXE 的关卡效果待测试。
TH06、TH08、TH09、TH12、TH13 和 TH19 尚未接入无敌；本机当前没有这些
游戏的可校验 EXE，不能把别作的受击位置直接套用。其他版本只支持原有变速功能。
“日文版限定”指当前核对过的 EXE 文件，不是游戏画面语言：若汉化仅改
外部文本而运行的还是同一份 thXX.exe，内存入口仍可复用；若汉化使用
thXXc.exe 等另一份程序，则代码位置和原字节须单独核对。本机的
th10chs.exe、th10cht.exe、th11c.exe 与日文 EXE 的 SHA-256 不同；
本开发版为它们分别校验文件指纹和受击代码后才允许启用。
无敌开关会临时修改运行中已识别游戏的受击代码，
取消勾选、切换进程或正常关闭工具时恢复；若恢复失败，请退出游戏。
TH16 日文版、TH18 和 TH20 的受击阻止效果已获使用者关卡确认；
擦弹和关闭恢复等细项仍待分别验证。
逐作测试时请先记下“开启后能否正常射击、Bomb、擦弹、拾取道具与切关”，
再取消勾选，确认可以正常受击。TH10 使用三字节返回指令，专门保持其
原函数的一个参数清栈行为；请特别留意开启和关闭时游戏是否稳定。
使用练习功能制作的录像可能不同步。

资源修改目前只保证内存数值已写入并回读。游戏界面和 Power 对应的攻击
配置可能延迟到下次游戏内部资源事件才同步；面板数字变化不代表攻击已经
同步。Bomb 使用逻辑直接读取内存数值，但可能受到正在放 Bomb 的状态限制。
请以实际关卡表现为准。
