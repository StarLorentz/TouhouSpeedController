# 练习功能开发路线

本路线用于把东方变速器逐步扩展为通用练习工具。每个阶段单独验证，
已经发布的 v0.1.1 在新功能稳定前保持不变。

## 不可跳过的安全规则

1. 通过游戏编号、文件名、PE 架构和 SHA-256 同时识别游戏版本。
2. 未命中已验证配置时只显示信息，不读取或写入游戏内存。
3. 写入代码前保存原始字节；关闭功能、游戏退出或工具退出时恢复。
4. 每个配置记录来源、支持的 EXE 哈希、验证项目和验证日期。
5. 汉化版、Steam 版和日文原版分别验证，不能仅凭文件名共用地址。
6. 练习功能产生的录像可能不同步，界面必须明确提示。

## 架构

- **界面层（C# / WinForms）**：自动识别进程，接受用户输入，展示当前值和支持状态。
- **控制协议**：延续现有命名管道方式，使用明确的读取、设置、冻结、恢复命令。
- **游戏适配层**：每个游戏版本拥有独立配置，包含哈希、地址、指针链和补丁。
- **进程内模块**：仅在必须拦截扣除或受击逻辑时使用；简单数值优先从外部安全读写。
- **变速模块**：继续使用 OpenSpeedy，与练习功能保持可独立启用和恢复。

## 阶段 1：版本识别地基（当前阶段）

- 建立第三方代码和许可证说明。
- 固定最初参考的 thprac 提交版本。
- 提供只读 EXE 指纹工具。
- 记录本机 TH16 日文版和汉化版的已知哈希。
- 不修改游戏内存，不改变当前程序行为。

## 阶段 2：TH16 资源读写

- 2A：只读显示当前残机、炸弹、炸弹碎片和 Power。
- 2B：确认两个已知 EXE 的读取结果后，再加入写入。
- 输入合法范围内的值并立即写入。
- 对地址和数据范围做二次验证，未知版本禁用按钮。

阶段 2A 调查记录：日文版可以按模块 RVA 安全读取；本机静态汉化版虽然来自同一
资源包，但其运行时内存布局不同。哈希识别已保留，资源读取暂时禁用，后续作为
独立配置分析，不能复用日文版地址。

## 阶段 3：TH16 无限资源

- 无限残机、无限炸弹和无限 Power 分别开关。
- 游戏正常执行消耗流程后恢复资源，避免使用超大数值造成溢出。
- 关闭开关后停止写入，不强制改变用户当前资源。

## 阶段 4：TH16 完全无敌

- 跳过敌方弹幕导致的受击分支。
- 保留擦弹、道具收集、射击、炸弹和正常画面。
- 保存并恢复被修改的原始指令。

## 阶段 5：逐作扩展

优先覆盖本机已有且能实测的作品。每增加一作，都重复版本识别、资源读写、
无限资源、无敌和恢复测试。TH09、TH10、TH11、TH19 等特殊资源系统单独设计界面语义。
